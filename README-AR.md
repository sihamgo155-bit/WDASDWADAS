# CIA CASA STREET RP — ELITE PORTAL

موقع Roleplay خيالي للألعاب، وليس موقعاً رسمياً تابعاً لأي جهة حكومية.

## محتويات المشروع
- `index.html`: الواجهة الرئيسية، التقديم واختبار QCM.
- `styles.css`: التصميم المتجاوب الأسود والأحمر.
- `app.js`: اللغات الثلاث (العربية، الإنجليزية، الإسبانية) والتفاعلات.
- `admin.html`: واجهة لوحة الإدارة التجريبية.
- `admin.css` و`admin.js`: تنسيق وتفاعلات لوحة الإدارة.
- `config.js`: إعدادات Supabase الاختيارية.

## النشر على GitHub Pages
ارفع ملفات المشروع الموجودة في الجذر إلى الـ repository، ثم افتح Settings → Pages، واختر Deploy from a branch، ثم `main` و`/(root)`.

## ملاحظة مهمة حول لوحة الإدارة والطلبات
هذه النسخة تحتوي على واجهة تقديم ولوحة إدارة أمامية، لكن الإدارة المشتركة بين الأجهزة ليست فعالة حتى يتم إعداد Backend حقيقي. لا تعتبر وضع Demo نظاماً آمناً أو دائماً.

لتفعيل العمل الحقيقي:
1. أنشئ مشروع Supabase.
2. نفّذ SQL آمن لإنشاء جدول الطلبات وسياسات RLS المناسبة.
3. انشر Edge Function لاستقبال الطلبات والتحقق من البيانات.
4. احتفظ بمفاتيح الخدمة وDiscord webhook في Supabase Secrets فقط، وليس في ملفات الموقع العامة.
5. فعّل تسجيل دخول إداري موثّق وتحقق من صلاحية المسؤول على الخادم قبل السماح بقبول/رفض الطلبات أو تعديل الأعضاء والرتب والمهام.

لا تستخدم كود دخول ثابتاً داخل JavaScript، لأنه يمكن لأي شخص رؤيته.
